# Word Document Generator

This project generates Word documents using python‑docx【498206288936468†L10-L33】. The script merges templates with data to create letters, invoices, or contracts.

## Features

- Creates and updates `.docx` files【498206288936468†L10-L33】.
- Adds headings, paragraphs, lists, and tables【498206288936468†L24-L58】.
- Inserts images or logos into documents.

## Prerequisites

- Python 3.8 or later.
- Install dependencies from `requirements.txt`.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Run the script to generate a sample document:
   ```
   python main.py
   ```
3. Modify `main.py` to use your own template and data.
