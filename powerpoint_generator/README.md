# PowerPoint Generator

This script builds PowerPoint presentations from data using the python‑pptx library【446216301474451†L10-L51】. The script reads analytics or report data and creates slides with charts and text.

## Features

- Creates presentations without Microsoft PowerPoint installed【446216301474451†L10-L51】.
- Adds slides with titles, text, tables, and charts.
- Inserts images or logos from files.
- Uses data from Excel or pandas DataFrame.

## Prerequisites

- Python 3.8 or later.
- Install dependencies from `requirements.txt`.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Place your data file as `data.csv`.
3. Run the script:
   ```
   python main.py
   ```
