# Office365 Python Projects

This repository provides sample Python projects for Microsoft 365 tasks and local troubleshooting. Each project has a dedicated folder with a README file, a requirements list, and sample code.

## Projects

- **active_directory_user_audit** – Audit Active Directory users, search for disabled accounts, and manage group memberships.
- **bulk_email_sender** – Send personalised emails in bulk using Microsoft Graph.
- **excel_report_generator** – Build Excel reports from data with charts and formatting.
- **powerpoint_generator** – Create slide decks from analytics or reports.
- **word_document_generator** – Generate Word documents such as invoices or letters.
- **calendar_event_scheduler** – Schedule calendar events from a CSV or database.
- **sharepoint_file_uploader** – Upload files to SharePoint document libraries.
- **teams_chat_automation** – Post messages to Teams channels and group chats.
- **outlook_email_parser** – Parse Outlook emails and download attachments.
- **graph_usage_dashboard** – Produce dashboards summarising Microsoft 365 usage.
- **system_diagnostics_tool** – Monitor system health on local machines.
- **hardware_driver_checker** – Review hardware drivers and versions.
- **network_connectivity_tester** – Test network reachability and latency.
- **automated_software_updater** – Update installed applications on your system.
- **web_based_diagnostic_dashboard** – Provide a web interface for diagnostics.

Use the README in each folder to set up and run the scripts.
