# Python-Projects

📦 A curated set of Python scripts across two levels:
- **Level 1**: Beginner-friendly CLI tools & utilities.
- **Level 2**: Intermediate scripts involving file I/O, APIs, or data parsing.

## 🧠 Scripts Included
- `script_name.py`: What it does, e.g. "Downloads images from a URL."
- `another_script.py`: Description, e.g. "Parses logs for error entries."

## 🚀 Tech Stack
- Python 3.10+
- Standard lib (os, argparse)
- [requests] or others (if used)
