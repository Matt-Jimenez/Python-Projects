# Excel Report Generator

This project reads raw data, performs calculations, and writes an Excel report with charts using openpyxl and pandas【364749106991556†L100-L136】.

## Features

- Reads data from CSV or databases using pandas.
- Performs summary calculations such as sums and averages.
- Writes results to a new workbook using openpyxl【364749106991556†L100-L136】.
- Adds basic charts and conditional formatting.

## Prerequisites

- Python 3.8 or later.
- Install dependencies from `requirements.txt`.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Place your raw data file as `data.csv`.
3. Run the script:
   ```
   python main.py
   ```
