# System Diagnostics Tool

This script monitors system health using the psutil library【679397079036653†screenshot】. The script reports CPU load, memory usage, disk space, and network throughput.

## Features

- Cross‑platform monitoring of system resources【679397079036653†screenshot】.
- Records CPU usage, memory usage, disk space, and network statistics.
- Generates a health report in plain text or JSON.
- Sends alerts when thresholds are exceeded.

## Prerequisites

- Python 3.8 or later.
- Install dependencies from `requirements.txt`.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Run the script to display current statistics:
   ```
   python main.py
   ```
